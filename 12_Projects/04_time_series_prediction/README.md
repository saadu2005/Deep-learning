# Time Series Prediction

## Purpose

Describe a starter project for forecasting future values from ordered measurements; this folder currently has a README only.

## Real-Life Example

A small retailer could forecast next week’s demand from daily sales records to plan stock levels.

Starter project for sequence-based prediction.

Possible datasets:
- Sales
- Stock prices
- Weather
- Energy consumption

Recommended models:
- RNN
- LSTM
- GRU
- Transformer
