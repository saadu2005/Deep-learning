# Datasets

Most lessons generate synthetic data or load built-in scikit-learn datasets. CNN and text projects load standard Keras MNIST, Fashion-MNIST, and IMDB datasets on demand; these downloads are managed by Keras and are **not** included in this repository. MobileNetV2 pretrained weights are downloaded separately. Do not commit private data, dataset archives or API keys. For custom data, document its licensing and preprocessing before sharing.
